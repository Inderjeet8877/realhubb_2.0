================================================================================
                        REALHUBB — COMPLETE PROJECT OVERVIEW
                        For Presentation / PPT Reference Document
================================================================================

PROJECT NAME    : RealHubb
WEBSITE         : www.realhubb.in
LOCATION        : Bengaluru, India
TYPE            : Real Estate Web Application (SPA – Single Page Application)
PURPOSE         : A full-featured real estate platform connecting property buyers
                  with premium property listings, developer profiles, market
                  insights, and financial planning tools across major Indian cities.

================================================================================
SECTION 1 — TECHNOLOGY STACK
================================================================================

FRONTEND
  - React 18          : Component-based UI library
  - TypeScript        : Strongly typed JavaScript for reliability
  - Vite              : Ultra-fast build tool and dev server
  - Tailwind CSS      : Utility-first CSS framework for rapid styling
  - shadcn/ui         : Pre-built, accessible React UI components
  - React Router DOM  : Client-side page routing (SPA navigation)
  - TanStack Query    : Server-state management and data fetching

BACKEND / SERVICES
  - Firebase Firestore   : Real-time NoSQL cloud database
  - Firebase Auth        : Secure email/password admin authentication
  - Cloudinary           : Image hosting and upload service (properties, blogs, team)
  - Firebase Functions   : Serverless functions for GA4 analytics & push notifications
  - Google Analytics 4   : Website traffic analytics and reporting
  - Web Push (FCM/VAPID) : Browser push notification system for subscribers

DEPLOYMENT
  - Vercel              : Frontend hosting and automatic CI/CD deployments
  - GitHub Actions      : Build check workflow on every push

================================================================================
SECTION 2 — WEBSITE ARCHITECTURE (TWO SIDES)
================================================================================

The application is split into two completely separate experiences:

  1. PUBLIC WEBSITE  — Accessible by all visitors (no login required)
                      Routes: /, /ongoing-projects, /blog, etc.
                      Includes: Header + Footer + Navigation

  2. ADMIN PANEL     — Password-protected back-office
                      Route: /admin/*
                      No public header/footer — standalone dashboard UI
                      Secured by: Firebase Authentication (email + password)

--------------------------------------------------------------------------------
ROLE 1: ADMIN (Back-Office Role)
--------------------------------------------------------------------------------

WHO IS AN ADMIN?
  The Admin is the internal team member (RealHubb staff) who logs into the
  private admin panel at /admin to manage all content on the website.
  There is one level of admin — secured by Firebase Authentication.

HOW THEY LOG IN:
  - Visit: www.realhubb.in/admin
  - Enter admin email (e.g. admin@realhubb.in) and password

  The admin panel has 6 main sections (navigation sidebar):

          * Properties with images
          * Properties with descriptions
          * Blog posts published
          * Developers with logos
          * Team members with photos
      - Quick Action buttons (Add Property, New Blog, Add Developer, Add Team)
      - SEO tips based on current score
      - External links to Firebase Console, Cloudinary, Live Site

  [B] PROPERTY MANAGER
      Full CRUD (Create, Read, Update, Delete) for property listings.

  [C] BLOG MANAGER
      Full CRUD for blog posts with a rich text editor.

  [D] DEVELOPERS MANAGER

SECTION 4 — PROPERTY MANAGER (Admin Feature — Detailed)
================================================================================

PURPOSE:
  The Property Manager is the core module of the admin panel. It allows the
  admin to add and manage all real estate listings that appear on the website.

HOW TO ACCESS:
  Admin Panel → Properties (left sidebar)

PROPERTY STATUSES:
  - Ongoing  : Properties currently under construction with active bookings
  - Upcoming : Projects announced but not yet launched for bookings

PROPERTY TYPES:
  - Apartment  : Multi-storey residential apartments
  - Villa      : Independent villa units
  - Plot       : Residential/commercial land parcels
  - Commercial : Office spaces, retail, commercial units

SUPPORTED CITIES:
  - Bangalore (primary)
  - Hyderabad
  - Chennai

PROPERTY FIELDS (All data stored in Firestore):
  1. Property Name     : Full project name (min 10 chars recommended for SEO)
  2. Developer         : Builder/developer name
  3. City              : Bangalore / Hyderabad / Chennai
  4. Location          : Specific locality (e.g. Whitefield, Bangalore)
  5. URL Slug          : Auto-generated from name; editable (used in page URL)
  6. Status            : Ongoing or Upcoming
  7. Type              : Apartment / Villa / Plot / Commercial
  8. Featured Flag     : Marks property as "Featured" — shown prominently
  9. Price Range       : Display price (e.g. ₹85L - ₹2.5Cr)
  10. Area             : Square footage range (e.g. 1200 - 2800 sq.ft)
  11. BHK Config       : Bedroom configuration (e.g. 2, 3, 4 BHK)
  12. Possession Date  : Expected handover date (e.g. Dec 2026)
  13. RERA Number      : Official registration number (adds legal trust signal)
  14. Description      : Full property description (150+ words recommended)
  15. Map Embed URL    : Google Maps iframe URL (improves local SEO)
  16. Amenities        : List of facilities (Swimming Pool, Gym, Clubhouse, etc.)
  17. Images           : Multiple photos (3-8 recommended; first = cover)

SEO SCORING (Live, per property):
  Each property gets an automatic SEO Health Score (0–100%) calculated from:
  - Property name length (≥10 characters)
  - Description length (≥50 characters)
  - Images uploaded (≥2 images)
  - Location and city filled
  - RERA number provided
  - Price listed
  - Map embed URL provided
  - Amenities listed (≥3)

  Score color coding:
  - Green (75–100%) : Good SEO
  - Amber (50–74%)  : Fair SEO
  - Red  (0–49%)    : Low SEO — needs improvement

FILTERING & SEARCH:
  - Search by property name, developer name, or location
  - Filter by City (All / Bangalore / Hyderabad / Chennai)
  - Filter by Status (All / Ongoing / Upcoming)
  - Stats strip shows: Total, Ongoing, Upcoming, Featured, SEO ≥75% counts

FIRESTORE INTEGRATION:
  - All changes are saved live to Firebase Firestore
  - Status indicator shows "Live · Firestore" or "Local only" in real time
  - Delete requires confirmation dialog (prevents accidental deletion)

SECTION 5 — BLOG MANAGER (Admin Feature — Detailed)
================================================================================

PURPOSE:
  The Blog Manager allows the admin to write, edit, and publish real estate
  articles and guides that appear on the /blog section of the website.
  Blogs drive organic SEO traffic and establish RealHubb as a market authority.

HOW TO ACCESS:
  Admin Panel → Blog Posts (left sidebar)

BLOG POST FIELDS:
  1. Cover Image        : Header image (1200×675px recommended; hosted on Cloudinary)
  2. Title              : Article headline (ideal: 30–60 characters for Google)
  3. URL Slug           : Auto-generated from title; editable
  4. Excerpt            : Meta description (ideal: 80–160 characters)
  5. Category           : Topic category (see categories list below)
  6. Author             : Author name (default: RealHubb Team)
  7. Read Time          : Estimated read time (e.g. 5 min read)
  8. Publish Date       : Date the post was/will be published
  9. Tags               : Keywords (min 2 recommended for SEO)
  10. Content           : Full article body with rich text editor
  11. Published Toggle  : Checked = live on site; Unchecked = saved as draft

BLOG CATEGORIES:
  - Real Estate News
  - Home Buying Guide
  - Investment Tips
  - RERA & Legal
  - Home Loans
  - Market Trends
  - Bangalore
  - Hyderabad
  - Chennai
  - Interior & Design

RICH TEXT EDITOR (Content Editor):
  The blog editor works like a mini word processor inside the browser.
  Available formatting tools:
  - normal (Ctrl+B)
  - Italic (Ctrl+I)
  - Heading 2 (H2) — Main article sections
  - Heading 3 (H3) — Sub-sections
  - Bullet List (unordered)
  - Numbered List (ordered)
  - Blockquote — highlighted quote block
  - Divider Line — horizontal separator
  - Insert Hyperlink (Ctrl+K) — wrap selected text or insert new link
  - Clear Formatting — removes all styling
  - Undo / Redo

  PREVIEW MODE: Toggle between Edit and Preview to see how the article
                will look on the live website before publishing.

  AUTO-SAVE: Editor auto-saves content reference on blur (timestamp shown).

PUBLISHED vs DRAFT:
  - Published = visible on the /blog listing page and searchable by Google
  - Draft = hidden from site; only visible in admin panel

SEO SCORING (Live, per blog post):
  Each post gets an automatic Blog SEO Score (0–100%) calculated from:
  - Title length (30–70 characters)
  - Excerpt/meta description (80–160 characters)
  - Cover image uploaded
  - Content word count (≥300 words)
  - Uses H2 or H3 headings in body
  - URL slug set (≥5 characters)
  - Category assigned
  - At least 2 tags added

WORD COUNT TARGETS (shown live in editor):
  - 300 words   = Minimum for SEO indexing
  - 600 words   = Good length
  - 1000+ words = Best for ranking

FILTERING:
  - Search by title, author, or category
  - Filter by Category
  - Filter by Status: All / Published / Draft

PAGE 10: EMI CALCULATOR  (/emi-calculator)
  PURPOSE: Calculate monthly home loan EMI before buying a property.
  INPUTS:
    - Loan Principal Amount (e.g. ₹50,00,000)
    - Annual Interest Rate (e.g. 8.5%)
    - Loan Tenure in Years (e.g. 20 years)
  OUTPUTS:
    - Monthly EMI amount
    - Total repayment amount over tenure
    - Total interest paid
    - Principal vs. Interest percentage breakdown (visual chart)
  USE CASE: Buyer enters property price to understand monthly burden.

PAGE 11: HOME LOAN ELIGIBILITY  (/home-loan-eligibility)
  PURPOSE: Check how much home loan you qualify for based on income.
  INPUTS:
    - Monthly income / salary
    - Existing EMI obligations
    - Interest rate
    - Loan tenure
  OUTPUTS:
    - Maximum loan amount eligible for
    - Estimated property budget
  USE CASE: Buyers understand their purchasing power before property search.

PAGE 12: RENTAL YIELD CALCULATOR  (/rental-yield-calculator)
  PURPOSE: Calculate the return on investment from rental income.
  INPUTS:
    - Property purchase price
    - Expected monthly rent
    - Annual maintenance / costs (optional)
  OUTPUTS:
    - Annual rental yield percentage
    - Net rental income
    - Comparison benchmarks
  USE CASE: Investors evaluate whether a property gives good rental returns.

PAGE 13: SALARY ADVISOR  (/salary-advisor)
  PURPOSE: Advise what price range of property suits your salary.
  INPUTS:
    - Monthly gross salary
    - Existing EMIs / liabilities
    - Down payment available
  OUTPUTS:
    - Recommended property budget range
    - Suggested loan amount
    - Suitable city/locality recommendations
  USE CASE: First-time buyers get guided property price bracket.

PAGE 14: CURRENCY CALCULATOR  (/currency-calculator)
  PURPOSE: Convert property prices from INR to other currencies.
  USE CASE: NRI buyers (Non-Resident Indians) planning to invest from abroad.
  INPUTS:  INR amount, target currency
  OUTPUTS: Converted amount in selected currency (live or approximate rates)

SECTION 10 — CROSS-CUTTING FEATURES (Applied Across the Whole App)
================================================================================

1. SEO OPTIMIZATION
   - Every page has custom meta titles and descriptions (SEO component)
   - Open Graph tags for social media sharing previews
   - Sitemap generation via Vite plugin (vite-sitemap-plugin)
   - Structured slugs for all property and blog URLs
   - Fast page load (Vite build optimization + Vercel CDN)

2. GOOGLE ANALYTICS 4 (GA4)
   - Tracks every page view across the SPA (even without full-page reloads)
   - Custom GA page tracker fires on every route change
   - Measurement ID: G-HPYW6VG3WR

3. SCROLL PROGRESS INDICATOR
   - Thin progress bar at the top of all public pages
   - Shows how far down the page the visitor has scrolled

4. SCROLL TO TOP
   - Automatically scrolls to the top when navigating between pages
   - Smooth scroll behavior

5. FADE-IN ON SCROLL ANIMATIONS
   - Content sections animate in as you scroll down
   - Creates a polished, modern feel

6. PARALLAX SECTIONS
   - Background images scroll at a different speed than content
   - Used on hero and feature sections for visual depth

7. WHATSAPP FLOATING BUTTON
   - Fixed WhatsApp chat button on all public pages
   - Opens a chat with RealHubb's WhatsApp number directly

8. LANGUAGE SELECTOR
   - Language selection component (multi-language support ready)

9. WEB PUSH NOTIFICATIONS
   - Visitors can subscribe to browser push notifications
   - Admin can send alerts to all subscribers from the dashboard
   - Powered by FCM/VAPID service worker (public/sw.js)
   - Subscriptions stored in Firebase Firestore (pushSubscriptions collection)

10. CLOUDINARY IMAGE MANAGEMENT
    - All images (properties, blogs, team, developers) hosted on Cloudinary
    - Images are served with optimization and CDN caching
    - Admin panel has dedicated image upload components (single and multi-image)
    - Supported formats: JPG, PNG, WebP, AVIF

11. FIRESTORE REAL-TIME DATABASE
    - All content (properties, blogs, team, developers) stored in Firestore
    - Changes in admin panel reflect on the live website immediately
    - Admin panel shows "Firestore Live" status indicator
    - Falls back to local hardcoded data if Firestore is unavailable
